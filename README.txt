통과 — 무역 영어 훈련 (모바일 독립 실행 버전)

이 폴더의 파일 전체를 https 주소로 열리는 곳에 그대로 올리면 됩니다.
서버 프로그램은 필요 없습니다 (정적 파일 호스팅).

1. GitHub Pages 예시
   - 새 저장소를 만들고 이 폴더의 파일 7개를 모두 업로드
   - Settings > Pages > Branch 를 main / (root) 로 지정
   - 몇 분 뒤 https://<계정>.github.io/<저장소>/ 로 접속
   (Netlify, Cloudflare Pages, 회사 웹서버도 같은 방식)

2. 휴대폰 홈 화면에 추가
   - 아이폰: Safari로 열기 > 공유 버튼 > 홈 화면에 추가
   - 안드로이드: Chrome으로 열기 > 메뉴 > 앱 설치 또는 홈 화면에 추가
   한 번 열고 나면 인터넷이 없어도 실행됩니다.

3. 말하기 모드
   처음 '말하기 시작'을 누르면 마이크 권한을 묻습니다. 허용해 주세요.

4. AI 생성 (선택)
   Google AI Studio (https://aistudio.google.com) 에서 Gemini API 키를 발급받아
   기록 탭 > 설정 > AI 생성용 Gemini API 키에 입력합니다.
   키는 그 휴대폰의 브라우저에만 저장됩니다. 이 앱 전용 키를 새로 만들어 쓰길 권장합니다.
   기본 모델은 gemini-3.8-flash 이고, 없으면 gemini-flash-latest 로 자동 전환합니다.
   모델을 바꾸려면 index.html 의 AI_MODELS 한 줄을 수정합니다.

5. 백업
   학습 기록은 기기 안에만 저장됩니다. 기록 탭 > 설정 > 기록·단어장 백업에서
   파일로 저장해 두면 다른 기기나 재설치 후에 불러올 수 있습니다.

6. 파일을 수정해서 다시 올릴 때
   sw.js 의 VERSION 값을 올려야 휴대폰에 새 버전이 반영됩니다.
